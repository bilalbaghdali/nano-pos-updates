# NANO POS v1.0.44 — الأيقونة الجديدة وشاشة الدخول العصرية

**12 أكتوبر 2026 — تحديث اختياري**

## التحسينات
- اعتماد أيقونة N زرقاء جديدة موحدة لشعار شاشة الدخول وأيقونة نافذة التطبيق.
- إعداد أيقونة ICO متعددة المقاسات في ملفات المشروع لاستخدامها في ملف Windows EXE والاختصارات عند إعادة بناء المثبت.
- إعادة تثبيت الشاشة العصرية التي قدمها المستخدم مرجعًا: لوحة دخول بيضاء على **اليسار** وخلفية زرقاء داكنة مع رسومات المبيعات والمخزون على **اليمين**.
- الإبقاء على أسماء المستخدمين وكلمات المرور، وزر الدخول، وأزرار اللغات AR / FR / EN، وحقول الإدخال القابلة للكتابة.
- إصلاح قاعدة CSS سابقة كانت تجعل عناصر بطاقة تسجيل الدخول تنتظم أفقيًا بشكل غير صحيح؛ أصبحت البطاقة عمودية.
- تم الحفاظ على ملفات الأعمال والنسخ الاحتياطية ونظام التفعيل والمزامنة.

## التحقق
- نجح بناء تطبيق app.asar عبر GitHub Actions والتحقق من بصمة الملف المنشور بعد تنزيله.
- اختبار محلي على Chromium عند 1366×768: لوحة التسجيل اليسرى وعرض الرسومات اليمنى، قابلية إدخال قيم الاختبار في الحقلين، وظهور أزرار اللغات الثلاث.
- اختبار تخطيط أصغر 900×800 لإظهار نموذج دخول واحد مناسب.
- **هذه اختبارات واجهة معزولة، وليست اختبار تشغيل كامل على جهاز Windows فعلي.**

## تنبيه أيقونة Windows
**ملف ZIP للتحديث التلقائي يستبدل app.asar** فقط. بذلك تتغير الأيقونة المستخدمة في نافذة التطبيق وشاشة الدخول. أما الأيقونة المدمجة أصلًا داخل EXE أو اختصار سطح المكتب الحالي فلا يمكن تغييرها عن طريق app.asar وحده؛ تحتاج إلى تثبيت نسخة EXE مبنية بالأيقونة الجديدة. تم بناء نسخة **Setup EXE** ونسخة **Portable EXE** بالأيقونة الجديدة، ونُشرتا ضمن [إصدار GitHub](https://github.com/bilalbaghdali/nano-pos-updates/releases/tag/v1.0.44).
