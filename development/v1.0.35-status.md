# NANO POS v1.0.35 — Release Candidate (11 October 2026)

**Status: release candidate / manual patch, not a production stable release.**

The existing public stable `nano-pos-update.json` **remains at 1.0.34** until an installable Windows artifact is hosted on a public direct URL and end-to-end installation, printing, LAN/Tailscale synchronization and data-preservation tests pass.

## Changes implemented in code
- Corrected the print-preview dialog's undefined active-state error; added localized classic/modern/compact layouts and customizable footer.
- Verified SHA-256 JSON backups, hourly automatic snapshots when a renderer snapshot is available and automatic-backup retention of up to 168 files. Manual backups are never pruned.
- Added server-side serialization and in-process deduplication of identical RPC operation IDs to reduce double submissions from remote clients. The cache is **not durable across restarts**.
- Preserved existing navigation speed patch, added keyboard shortcuts for home/sales/products/financial reports and F2 POS search.
- Added pre-deduction quantity, price and batch-stock checks to POS sales.
- Added a financial overview with estimated gross/net profits, sales, expenses, receivables, payables, low stock, daily sales, top products and CSV export.
- Added three print style presets with persisted footer text.
- Updated current-version feature notes to reflect 1.0.35.
- **Critical safety:** disabled the previous first-run clean-data flag and stopped deleting the old `cloud-backup` directory.

## Automated tests
Six Node tests passed for backup, data-preservation checks, financial aggregation, in-process deduplication, and serialized operations; ZIP archive integrity checked.
