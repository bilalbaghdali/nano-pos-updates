# NANO POS v1.0.38 — النسخ السحابي المباشر عبر MEGA (دون MEGAcmd)

**11 أكتوبر 2026 · تحديث اختياري من v1.0.34 أو v1.0.35 أو v1.0.36 أو v1.0.37**

## ما الجديد
- الاتصال مباشرة بـ MEGA من الإعدادات ← إدارة البيانات، دون تنزيل MEGAcmd أو تثبيت أدوات إضافية.
- تضمين مكتبة MEGAJS 1.3.10 وتبعياتها **داخل app.asar** نفسه، مع فحص الاستيراد في GitHub Actions.
- تسجيل دخول بالبريد الإلكتروني وكلمة المرور ورمز التحقق الثنائي عند الحاجة.
- حفظ جلسة الحساب باستخدام تشفير Electron safeStorage / Windows DPAPI؛ لا تُخزّن الجلسة كنص مكشوف.
- بعد تسجيل الدخول، يحاول البرنامج حفظ نسخة محلية حديثة إن توافرت بيانات، ثم يرفع أحدث نسخة اجتازت فحص SHA-256.
- خيار النسخ التلقائي كل ساعة مع الاحتفاظ بالنسخ المحلية، واستعراض النسخ ونسخ الاستعادة إلى مجلد منفصل دون المساس بالبيانات الحية.
- إضافة زر فصل الحساب ومسح ملف الجلسة المحمي.
- إلغاء الحاجة إلى MEGAcmd كاعتماد للنسخ الاحتياطي الجديد.

## إعداد النسخ السحابي
1. حدّث NANO POS إلى v1.0.38 عبر الإعدادات ← التحديثات.
2. افتح الإعدادات ← إدارة البيانات ← النسخ الاحتياطي السحابي عبر MEGA.
3. أدخل بريد MEGA وكلمة المرور ورمز المصادقة الثنائية إن ظهر.
4. اضغط «ربط الحساب والنسخ الآن».
5. راقب حالة النسخ والملف الأخير، ثم اختبر تنزيل إحدى النسخ إلى مجلد استعادة.

## الاختبارات والأمان
- **9 اختبارات محلية ناجحة**: التحقق من نسخ البيانات، وحفظ الجلسة بشكل محمي، واستئناف الجلسة، ومنع استعادة ملف تالف أو تجاوز المسارات، وغير ذلك.
- تحقق GitHub Actions من الإصدار المصدر السابق، وتضمين 101 ملفًا من تبعيات MEGAJS وفحص الاستيراد دون اتصال فعلي.
- تطابق بصمة ملف الإصدار التي تم تنزيلها مع الملف الذي بُني ونُشر.
- **لم يُختبر تسجيل الدخول والرفع بحساب MEGA حقيقي على جهاز Windows**؛ اعتماد الميزة الفعلي يحتاج اختبارًا ميدانيًا. احتفظ بنسخة محلية مستقلة.
- إذا كانت حماية Windows غير متاحة، لا تحفظ الجلسة بصورة غير مشفرة؛ سيظل الاتصال الحالي متاحًا، وقد يتطلب الدخول من جديد بعد إغلاق التطبيق.
- MEGAJS مكتبة JavaScript **غير رسمية**، ويجب تقييم توافقها وأمانها قبل الاعتماد عليها في إنتاج حساس.
