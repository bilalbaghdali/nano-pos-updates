# NANO POS v1.0.45 — إصلاح شاشة الدخول التي تظهر فعليًا

**12 أكتوبر 2026 — تحديث اختياري**

## المشكلة التي جرى تحديدها
كانت شاشة NANO POS العصرية موجودة بالفعل في عنصر `#loginOverlay`، لكن نظام تسجيل الدخول المحلي `browser-ui.js` ينشئ عنصرًا ثانيًا هو `#nanoLocalLoginOverlay` ويعرضه فوق الشاشة الأولى. ولهذا ظل المستخدم يرى نموذج «خدمات تقنية» البسيط رغم تثبيت v1.0.44.

## التحسينات
- تحويل نافذة الدخول **المستخدمة فعليًا لتسجيل المستخدمين** إلى تصميم عصري ببطاقة بيضاء في الجهة اليسرى، وخلفية زرقاء داكنة على اليمين تعرض رسومات المبيعات والمخزون.
- استخدام شعار NANO POS الأزرق الجديد داخل بطاقة الدخول، مع إبقاء اسم المتجر.
- توفير أزرار AR وFR وEN داخل نافذة الدخول الحقيقية.
- إبقاء نفس حقول اسم المستخدم وكلمة المرور وزر الدخول، مع **عدم تغيير** مستمع أحداث المصادقة أو قاعدة المستخدمين أو الترخيص.
- إبقاء اختيار المستخدم عبر المتصفح البعيد كما كان؛ التغيير خاص بشاشة الكمبيوتر المحلية.

## التحقق
- جرى اختبار مستقل للواجهة في Chromium بعرض 1366×768 و900×800 مع إدخال اسم المستخدم وكلمة المرور وتفعيل إرسال النموذج وإخفاء الشاشة بعد الدخول.
- نجح بناء GitHub Actions للحزمة v1.0.45 من الإصدار v1.0.44 الموثّق، والتحقق من سلامة ملف ZIP المنشور وبصمته.
- **لم يتم تشغيل تحديث v1.0.45 بعد على جهاز Windows الخاص بالمحل**؛ اختبار المصادقة النهائي على الجهاز يبقى ضروريًا.
