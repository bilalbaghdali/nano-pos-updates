# NANO POS v1.0.37 — تسجيل دخول MEGA داخل البرنامج

**نُشر بتاريخ 11 أكتوبر 2026 · تحديث اختياري من v1.0.34/v1.0.35/v1.0.36**

## المميزات
- أمام خيارات النسخ الاحتياطي في **الإعدادات ← إدارة البيانات** تظهر خانات بريد MEGA وكلمة المرور ورمز التحقق الثنائي الاختياري.
- عند نجاح تسجيل الدخول، تُنشأ نسخة احتياطية محلية متحقق منها من حالة البرنامج الحالية إن توفرت، ثم تُرسل إلى مجلد `/NANO-POS-Backups` على MEGA.
- بعد الربط تُفعّل مزامنة النسخ الاحتياطية السحابية كل ساعة مع الاستمرار في حفظ نسخ الكمبيوتر.
- يحتفظ MEGAcmd الرسمي بجلسة الحساب بين تشغيلات التطبيق؛ تختفي خانات التسجيل عند اتصال الجلسة، ولن يُطلب إدخال كلمة المرور مرة أخرى إلا عند انتهاء الجلسة أو تسجيل الخروج.
- بيانات الدخول ورمز التحقق لا تُحفظ داخل قاعدة بيانات NANO POS أو ملف إعدادات النسخ الاحتياطي.
- يتم تمرير بيانات الدخول وقت المصادقة إلى MEGAcmd Shell عبر قناة إدخال مؤقتة، وليس ضمن معاملات سطر الأوامر، لتجنب ظهورها في قائمة العمليات.

## قبل التشغيل
1. تثبيت MEGAcmd الرسمي من https://mega.nz/cmd.
2. من NANO POS: الإعدادات ← إدارة البيانات ← النسخ الاحتياطي السحابي عبر MEGA.
3. إدخال بريد الحساب وكلمة المرور ورمز التحقق الثنائي إن كان مفعّلًا.
4. الضغط على **ربط الحساب والنسخ الآن**.
5. راقب نتيجة «آخر رفع»، ثم اختبر الاسترجاع إلى مجلد آمن دون استبدال قاعدة بيانات المحل.

## ملاحظات السلامة
**اختبار إدخال الحساب عبر MEGAcmd Shell على Windows بحساب MEGA حقيقي لم يتم ميدانيًا.** نجحت اختبارات منطق الخدمة البرمجية (14 اختبارًا من دون أخطاء) ونجح بناء ملف GitHub وفحص تنزيله وبصمة SHA-256. إذا لم ينجح ربط الحساب من داخل NANO POS، يمكن استخدام تسجيل الدخول التقليدي من MEGAcmd Shell مرة واحدة، ثم استخدام زر فحص الاتصال والرفع اليدوي. لا تحفظ كلمات المرور في ملف نصي. احتفظ بنسخة محلية مستقلة من قاعدة بيانات المتجر.

**التحديث ليس إجباريًا، ولا يستبدل البيانات الحية تلقائيًا.**
