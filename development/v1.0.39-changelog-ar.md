# NANO POS v1.0.39 — تحسينات استقرار النظام

**11 أكتوبر 2026 — تحديث اختياري**

## إصلاحات الاستقرار
- **فواتير البيع:** تظهر أسماء الزبائن الذين أُضيفوا أو عُدّلوا مباشرة في اختيار الزبون دون إعادة تشغيل البرنامج؛ يتم تحديث ذاكرة الأسماء بعد الحفظ وعند فتح بحث الزبون.
- **فواتير الشراء:** يتم تحديث الموردين بعد الإضافة والتعديل، ويُعاد جلب قائمتهم عند تجهيز فاتورة شراء؛ يتم الحفاظ على الاختيار الجاري إذا كان المورد ما زال موجودًا.
- **إضافة منتج:** بعد نجاح حفظ *منتج جديد* تبقى نافذة إضافة المنتج ظاهرة ويُعاد تهيئة نموذجها للمنتج التالي، ويعود المؤشر إلى اسم المنتج. توليد الباركود الآلي والقيم الافتراضية يظلان كما كانا.
- **تعديل المنتجات الموجودة:** لم يتغير سلوك الحفظ والإغلاق، وكذلك جميع بيانات البيع والشراء والمخزون والنسخ الاحتياطية.

## الفحوصات
- 13 تحققًا من شفرة الإصلاح والحزمة المصدرية.
- `node --check` على JavaScript المعدل ضمن GitHub Actions.
- إعادة بناء `app.asar` من **v1.0.38** المنشورة مع مطابقة بصمات النسخة الأصلية والملفات الأربعة المستبدلة.
- اجتاز GitHub Actions بناء الملف وفحص SHA-256 بعد تنزيل الملف المنشور.
- **لم يُجر اختبار تفاعلي كامل على Windows أو قياس سلوك التزامن بين عدة أجهزة ميدانيًا**. خذ نسخة احتياطية مستقلة قبل تحديث متجر فعلي.
