# NANO POS v1.0.36 — إزالة التقرير المكرر وإضافة نسخ MEGA
**نُشر في 11 أكتوبر 2026 · تحديث اختياري من v1.0.34 أو v1.0.35**

## ما تغيّر
- إزالة نافذة التقرير المالي المتقدم الإضافية التي ظهرت في v1.0.35، بما فيها البطاقات الإحصائية المضافة فوق الصفحة الرئيسية.
- الاحتفاظ بلوحة الإحصائيات الأصلية وكل صفحات التقارير المضمنة مسبقًا.
- إضافة قسم **MEGA Cloud Backup** في الإعدادات ← إدارة البيانات على تطبيق Windows.
- الفحص المباشر لحالة MEGAcmd، والرفع اليدوي لأحدث نسخة محلية محققة.
- خيار **معطّل افتراضيًا** لرفع النسخ الاحتياطية كل ساعة بعد حفظها محليًا.
- عرض أسماء النسخ المخزنة في MEGA، وتنزيل نسخة محددة إلى مجلد استرداد دون تغيير البيانات الحية.
- فحص SHA-256 للنسخة المحلية قبل الرفع وللنسخة السحابية بعد التنزيل.
- بيانات الدخول لا تُحفظ في NANO POS؛ جلسة الدخول تديرها MEGAcmd الرسمية.

## إعداد حساب MEGA
1. تثبيت [MEGAcmd الرسمي](https://mega.nz/cmd) على الكمبيوتر Windows.
2. فتح **MEGAcmd Shell** من قائمة Start وتسجيل الدخول إلى حساب MEGA.
3. فتح NANO POS → الإعدادات → إدارة البيانات → MEGA → فحص الاتصال.
4. الضغط على «رفع أحدث نسخة» للتجربة، ثم تفعيل الرفع التلقائي إن رغبت.
5. تحفظ النسخ في المسار `/NANO-POS-Backups` بحسابك على MEGA.

## الأمان والقيود
- هذا **نسخ احتياطي** وليس تزامنًا فوريًا لقاعدة بيانات عدة أجهزة.
- **لا حذف** للنسخ المحلية بعد الرفع؛ **لا استعادة تلقائية** على قاعدة البيانات الحية.
- لا يعمل تكامل MEGA قبل تثبيت MEGAcmd وتسجيل الدخول عليه، ويحتاج إلى اتصال إنترنت.
- نجحت اختبارات مكونات النسخ 10/10 على Node مع محاكاة أوامر MEGAcmd، ونجحت GitHub Actions بإعادة بناء ملف التحديث والتحقق من التنزيل و SHA-256.
- **لم يُختبر حساب MEGA الفعلي أو تشغيل أوامر MEGAcmd على Windows ميدانيًا**. احفظ نسخة احتياطية مستقلة قبل التطبيق الإنتاجي.
